Contributing to Mini Chat Simulator – AI Replies

Thank you for showing interest in contributing!  
This project is simple, beginner-friendly, and open to improvements.  
Follow the guidelines below to keep everything clean and easy to maintain.

---

 📝 How to Contribute

 1. Fork the Repository
Click *Fork* on the top-right of the repo page to create your own copy.

 2. Create a New Branch
Use clear branch names such as:
- feature-new-reply-system
- fix-mood-detection
- refactor-code-style

Example:

git checkout -b feature-improved-responses

 3. Make Your Changes
Improve code, fix bugs, add features, or enhance documentation.

Please ensure:
- Code remains *simple* and *console-based*
- No heavy libraries are added
- GDB Online compatibility stays intact

 4. Commit Your Changes
Use meaningful commit messages:

Added enhanced mood detection logic

or

Improved reply randomness for natural responses

 5. Push Your Branch

git push origin feature-improved-responses

 6. Open a Pull Request
Go to your repository → *Pull Requests* → *New Pull Request*

Describe:
- What you improved
- Why it’s useful
- Any testing done

---

 ⭐ What You Can Contribute

- New AI-style replies  
- Better mood detection  
- Improved random reply system  
- Cleaner code structure  
- Bug fixes  
- Documentation updates  
- New example interactions  
- Optimizations for speed  

---

 📌 Code Style Guidelines

- Keep code *short, **clear, and **readable*
- Use simple logic instead of heavy AI libraries
- Maintain compatibility with *OnlineGDB*
- Use consistent formatting and indentation

---

 🤝 Community Rules

- Be respectful and supportive  
- No spam or irrelevant contributions  
- Keep pull requests small and focused  

---

 💬 Need Help?
Open an *Issue* in the repository and describe your question or problem.

Happy contributing! 🎉
