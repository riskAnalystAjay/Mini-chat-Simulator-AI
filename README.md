Mini Chat Simulator – AI-Like Replies

A lightweight and fast AI-style chat simulator built in C#.  
It generates short, smart, human-like replies using simple mood and keyword detection.

 🚀 Features
- Detects emotion from user text (happy, sad, angry)
- Auto replies to questions
- Natural and fun AI-like responses
- Fully compatible with GDB Online
- Zero external libraries
- Perfect starter AI/chatbot project

 💻 How It Works
The bot checks your message for:
- Mood keywords (happy, sad, angry)
- Greetings (hi, hey, hello)
- Questions (?)
- And randomly picks natural replies when no mood detected
